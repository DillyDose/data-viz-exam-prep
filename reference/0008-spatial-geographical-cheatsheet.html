Spatial & Geographical Data Cheat Sheet

เทคนิคหลัก

เทคนิคVisual Variableจุดแข็งกับดัก
Choropleth Mapสี (hue/lightness) ระบายทั้งพื้นที่คุ้นตา อ่านง่ายพื้นที่ใหญ่แต่ประชากรน้อยเด่นเกินจริง ("land doesn't vote")
Cartogramขนาด/รูปทรงพื้นที่ถูกบิดตามข้อมูล (เช่นประชากร)แก้ปัญหาพื้นที่เด่นเกินจริงของ choroplethรูปทรงจำไม่ได้ อ่านตำแหน่งจริงยาก
(Proportional) Symbol Mapขนาด mark (วงกลม ฯลฯ) วางตามตำแหน่งรักษารูปทรงภูมิศาสตร์จริงไว้ต้อง scale ด้วยพื้นที่ ไม่ใช่รัศมี (เหมือน Lecture 2)
Tile Grid MapContainment/position เป็นสัญลักษณ์เท่ากันทุกพื้นที่ทุกพื้นที่ (รัฐ/จังหวัด) มีน้ำหนักภาพเท่ากัน ไม่ถูกพื้นที่ใหญ่บังเสียรูปทรง/ตำแหน่งภูมิศาสตร์จริง
Flow Mapเส้น (ความหนา/สี) ทับแผนที่จริงเห็นทิศทาง/ปริมาณการเคลื่อนที่เส้นทับกันเยอะเมื่อข้อมูลหนาแน่น (เหมือน node-link hairball)

Choropleth Map Colors

  • Hue → nominal data (หมวดหมู่)
  • Lightness/Saturation → ordinal/quantitative data (ไล่ระดับเข้ม-อ่อน)
  • ห้ามใช้ rainbow colormap — ไล่ระดับไม่เป็นเส้นตรงในสายตา บอกไม่ได้ว่าสีไหน "มากกว่า" สีไหน
  • ใช้ 1-2 hue พอ (หรือ diverging scale ถ้าข้อมูลมีจุดกึ่งกลางที่มีความหมาย เช่น 0)

การเลือก Threshold สำหรับ Choropleth

  • Min/Max, Min/Median/Max, Quartiles — วิธีง่าย ใช้ได้ทั่วไป
  • Non-linear mapping (เช่น log scale) — เมื่อข้อมูลเบ้มาก
  • Jenks Natural Breaks — หาจุดแบ่งที่ minimize in-class variance และ maximize between-class variance (หา "หุบเขา" ของ histogram)
MAUP: Modifiable Areal Unit Problem
ข้อมูลชุดเดียวกัน วาดผลต่างกันได้ ถ้าขอบเขตพื้นที่ (เช่น เขตเลือกตั้ง, จังหวัด) เปลี่ยนไป — สรุปผลจาก choropleth map ต้องเช็คเสมอว่า "ขอบเขตพื้นที่ที่ใช้เปลี่ยนไปหรือเปล่า" ก่อนเทียบสองแผนที่ข้ามช่วงเวลา

Map Projection

ไม่มี projection ไหนรักษาทั้งพื้นที่ ระยะทาง และรูปทรงได้ถูกต้องพร้อมกัน — Mercator projection (ที่ใช้ในแผนที่เว็บทั่วไป) บิดเบือนพื้นที่แถบขั้วโลกให้ดูใหญ่เกินจริงมาก (เช่น กรีนแลนด์ดูใหญ่พอ ๆ กับแอฟริกา ทั้งที่จริงเล็กกว่ามาก 14 เท่า)

ทางเลือกจัดการจุดซ้อนทับบนแผนที่ (คล้าย overplotting ใน scatter plot)

  • Spike Map — แท่งพุ่งขึ้นแนวตั้งแทนวงกลม ลดการซ้อนทับ
  • Necklace Map — ดึง symbol ออกมาเรียงรอบขอบพื้นที่แทนวางทับตำแหน่งจริง
  • Voronoi Diagram — แบ่งพื้นที่ตามจุดที่ใกล้ที่สุด ช่วยจัด symbol ไม่ให้ทับกัน
  • Sampling/Stippling — สุ่มแสดงจุดบางส่วนแทนทั้งหมด (หลักการเดียวกับ Lecture 5)
