Scaffolding & Univariate Chart Checklist

Complete Chart = Scaffolding + Content

(Alberto Cairo) Content คือรูปทรง/มาร์กที่เข้ารหัสข้อมูลจริง ส่วน Scaffolding คือทุกอย่างที่ช่วยให้ตีความ content ได้ถูกต้อง — ถ้าลอก scaffolding ออกจนหมด content จะกลายเป็นรูปทรงที่ตีความไม่ได้เลย.

  • Title / description
  • Axes
  • Legends
  • Annotations

กฎ Tick Marks (4 ข้อ)

หลักการความหมาย
Simplicityใช้ตัวคูณของ 2, 5, 10 …
Coverageครอบคลุมข้อมูลทั้งหมด แต่ไม่เกินความจำเป็น
Densityไม่ถี่หรือห่างเกินไป
Legibilityตัวอักษรแนวนอนใหญ่พออ่านได้

กระบวนการออกแบบ Univariate Chart

  1. Determine the data type (nominal/ordinal/quantitative)
  2. Pick one appropriate visual variable
  3. เติม scaffolding: title, axes, legends, annotations

Code Tools → เชื่อมกลับกรอบคิดหลัก

ข้อดีของเครื่องมือแบบ code (D3.js, Vega, Altair, R)เชื่อมกับ
Pixel precise→ Truthful
Reusable—
(Possibly) interactive→ Insightful

Grammar Stack: Altair → Vega-Lite → Vega

Altair (Python spec) → คอมไพล์เป็น Vega-Lite spec (JSON) → คอมไพล์เป็น Vega spec (JSON) → เรนเดอร์เป็น Visualization จริง

Data Type Suffix ใน Altair

Suffixความหมาย
:QQuantitative
:OOrdinal
:NNominal

เช่น encode(color='x:Q') บอก Altair ว่าคอลัมน์ x เป็นข้อมูลเชิงปริมาณ ให้เลือกสเกลสีแบบไล่ระดับ (ไม่ใช่สีตามหมวดหมู่)
