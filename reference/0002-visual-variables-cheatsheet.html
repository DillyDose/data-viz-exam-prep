Visual Variables (Channels) Cheat Sheet

Marks vs Variables

  • Visual Mark — รูปทรงพื้นฐานที่แทน 1 data point (จุด, เส้น, สี่เหลี่ยม, วงกลม)
  • Visual Variable / Channel — คุณสมบัติที่ใช้เข้ารหัส (encode) ค่าข้อมูลลงบน mark เช่น ความยาว พื้นที่ ความเข้มสี เฉดสี ตำแหน่ง มุม

จับคู่ Channel กับประเภทข้อมูล

ประเภทข้อมูลนิยามChannel ที่เหมาะ
Ordinal / Quantitativeมีลำดับ/สเกลต่อเนื่อง (x → x+a)ตำแหน่ง (position), ความยาว (length), มุม (angle), ขนาด (size/area), ความเข้ม (darkness/brightness)
Nominal / Categoricalไม่มีลำดับโดยธรรมชาติเฉดสี (hue), รูปทรง (shape)

กับดัก: เฉดสี (hue) ใช้กับข้อมูลเชิงปริมาณไม่ได้ดี เพราะสมองจัดลำดับสีไม่ได้ตามธรรมชาติ (แดงไม่ได้ "มากกว่า" น้ำเงิน) — ใช้ความเข้ม/ความสว่างของสีเดียวแทนสำหรับข้อมูลเชิงปริมาณ

อันดับความแม่นยำของการรับรู้ (Perceptual Accuracy Ranking)

จาก Cleveland & McGill (1984) ที่ Heer & Bostock (2010) ทดสอบซ้ำผ่าน crowdsourcing บน Mechanical Turk และ Tamara Munzner สรุปไว้ใน Visualization Analysis and Design (2014) — เรียงจาก error ต่ำสุด (แม่นสุด) ไปสูงสุด (แม่นน้อยสุด):

  1. Position (ตำแหน่งบนแกนร่วม) — แม่นยำที่สุด
  2. Angle (มุม เช่น pie chart)
  3. Circular area (พื้นที่วงกลม เช่น bubble chart)
  4. Rectangular area (พื้นที่สี่เหลี่ยม เช่น treemap) — แม่นยำน้อยที่สุด
นัยสำคัญต่อการเลือกชาร์ต
นี่คือเหตุผลเชิงวิทยาศาสตร์ว่าทำไม bar chart (position) แม่นยำกว่า pie chart (angle) และ bubble chart (area) เมื่อผู้อ่านต้องเปรียบเทียบค่าที่แม่นยำ — ไม่ใช่แค่ความชอบส่วนตัว

3 กับดัก "ไม่ Truthful" ที่พบบ่อย (ตัวอย่างจาก slide)

  • Pie chart ที่ผลรวม % เกิน 100% — เช่นตัวอย่าง Fox News 2012 GOP pie chart (70% + 63% + 60% = 193%) ทำให้สัดส่วนภาพไม่ตรงกับข้อมูลจริง
  • แกน bar chart ไม่เริ่มที่ 0 — ทำให้ผลต่างระหว่างแท่งดูเกินจริง
  • Proportional symbol (วงกลมตามขนาดข้อมูล) ที่ scale ผิด — ถ้าใช้ "รัศมี" แทน "พื้นที่" ในการ scale ตามค่าข้อมูล จะทำให้ค่าที่มากดูใหญ่เกินจริงมาก (พื้นที่วงกลมโตเป็นกำลังสองของรัศมี)

Color Perception — ข้อจำกัดทางสรีรวิทยา

  • Chromatic aberration / Chromostereopsis — เลนส์ตาโฟกัสสีแดงกับสีน้ำเงินพร้อมกันไม่ได้ ทำให้ตัวอักษรสีแดงบนพื้นน้ำเงิน (หรือกลับกัน) ดูเบลอ อ่านยาก
  • Color blindness — ~8% ของประชากรโลก (ส่วนใหญ่เพศชาย) มี deuteranopia (บกพร่องการแยกแดง/เขียว) — หลีกเลี่ยงการเข้ารหัสข้อมูลสำคัญด้วยคู่สีแดง-เขียวเพียงอย่างเดียว
