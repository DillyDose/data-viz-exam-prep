Visual Analytics Cheat Sheet

นิยามสั้น

Visual Analytics = Visualization + Interaction + (บ่อยครั้ง) Machine Learning/Analysis อัตโนมัติ — ใช้ตอบคำถามที่ยังไม่รู้คำตอบ (to explore) ผ่านการวนลูป: ดูภาพ → ตั้งสมมติฐาน → โต้ตอบเพื่อเจาะลึก/กรอง → เห็น pattern ใหม่ → ตั้งคำถามใหม่ (Sensemaking Loop)

Visual Analytics Mantras (เทียบ 3 แบบ)

Mantraผู้เสนอใจความ
Visual Information Seeking MantraBen Shneiderman, 1996Overview first, zoom and filter, then details-on-demand
Visual Analytics MantraDaniel Keim, 2006Analyze first, show the important, zoom/filter/analyze further, details on demand
"Namredienhs" Mantra (Shneiderman สลับตัวอักษร)van den Elzen & van Wijk, 2014Details, select & aggregate, overview

Keim ปรับจาก "Overview first" เป็น "Analyze first" เพราะข้อมูลยุค Big Data ใหญ่เกินกว่าจะแสดง overview ที่มีความหมายได้เลยตั้งแต่ต้น (ต้องให้ machine วิเคราะห์/ย่อยก่อน ถึงจะมี overview ให้ดู)

Sensemaking ในทางปฏิบัติ

  • Closed-ended คำถาม: มีคำตอบเดียวชัดเจน (เช่น "ปีไหนได้เหรียญทองเยอะสุด")
  • Open-ended คำถาม: "How & Why" — ต้องอาศัยการสำรวจ ไม่มีคำตอบสำเร็จรูป ถ้าเครื่องมือควบคุมผู้ใช้มากเกินไป (ให้ทางเลือกน้อยเกินไป) จะตอบคำถามแบบนี้ไม่ได้

Explainable AI (XAI) = Visual Analytics ประยุกต์กับโมเดล ML

โมเดล ML สมัยใหม่ (โดยเฉพาะ deep learning) มักเป็น "black box" — รู้ input/output แต่ไม่รู้กลไกภายใน แนวทางแก้ 2 แบบหลัก:

  • สร้างโมเดลใหม่มาอธิบายโมเดลเดิม (surrogate model ที่ตีความง่ายกว่า)
  • Visualize โมเดลเดิมตรง ๆ ผ่านเครื่องมือเช่น Squares, LSTMVis, seq2seq-vis

เหตุผลที่ต้องมี XAI: ความน่าเชื่อถือ (trust), ตรวจจับ bias/ความไม่เป็นธรรม (fairness), debug โมเดลที่ทำงานผิดพลาด
