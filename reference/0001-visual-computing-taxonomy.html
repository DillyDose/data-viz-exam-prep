Visual Computing แผนที่ทั้งสาขา

เอกสารนี้สรุป diagram จาก slide เรื่อง Visual Computing ให้ใช้ทบทวนไว หากข้อสอบถามให้จำแนกว่าเทคนิคหนึ่งอยู่ตรงไหนของสาขา.

แกนหลัก: Data ↔ Image

สาขาทิศทางนิยามสั้น
Computer GraphicsData → Imageสร้างภาพ (มักเน้น realistic) จากข้อมูล/โมเดล
Image ProcessingImage → Imageแปลงภาพเป็นภาพ (เช่น กรอง, ปรับสี)
Computer VisionImage → Dataสกัดข้อมูล/ความหมายออกจากภาพ
VisualizationData → Imageสร้างภาพจากข้อมูล เพื่อสื่อสาร ไม่เน้น realistic แต่เน้นสื่อความหมาย

Non-Visual Computing คือส่วนที่ไม่เกี่ยวกับภาพเลย (data ↔ data / text ↔ text) — ใช้แยก visualization ออกจากงาน data processing ทั่วไปที่ไม่สร้างภาพ.

ใน Visualization เอง: Realistic → Abstract

  • Scientific Visualization — ข้อมูลมีมิติเชิงพื้นที่/กายภาพจริง (เช่น การไหลของอากาศ, MRI) → ค่อนไปทาง realistic
  • Information Visualization — ข้อมูลนามธรรม ไม่มีมิติเชิงพื้นที่โดยธรรมชาติ (เช่น ยอดขาย, เครือข่ายสังคม) → abstract เต็มตัว
  • Visual Analytics — ผสาน visualization เข้ากับการวิเคราะห์เชิงโต้ตอบ (interactive) เพื่อหา insight ไม่ใช่แค่แสดงผล
จำไว้สั้น ๆ
Visualization = Computer Graphics ที่ "เสียสละความสมจริงเพื่อความหมาย" — เป้าหมายคือสื่อสารข้อมูลให้เข้าใจง่ายและถูกต้อง ไม่ใช่ให้ภาพสวยเหมือนจริง.
