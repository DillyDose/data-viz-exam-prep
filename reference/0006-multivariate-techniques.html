Multivariate Visualization Techniques

เทคนิคหลักการข้อควรระวัง
Ternary Plot3 ตัวแปรที่รวมกันได้ค่าคงที่ (เช่น สัดส่วน 100%) พล็อตในสามเหลี่ยม 2Dใช้ได้เฉพาะเมื่อ 3 ตัวแปรบวกกันเป็นค่าคงที่เท่านั้น
Glyph (เช่น Chernoff Face)รวมหลาย visual variable ไว้ใน mark เดียว (ไอคอนผสม) แต่ละมิติข้อมูล = 1 คุณลักษณะของ glyphยิ่งมิติเยอะ ยิ่งตีความยาก ต้องมี legend อธิบายการแมปชัดเจน
Dimension Stackingซ้อนหลายมิติ categorical เข้าไปใน chart เดียว ผ่าน facet (column/row) + colorเพิ่มมิติเรื่อย ๆ จะทำให้ subplot เล็กจนอ่านยาก
Scatterplot Matrix (SPLOM)ตาราง scatter plot ของทุกคู่ตัวแปร (pairwise)จำนวน subplot โต O(n²) ตามจำนวนตัวแปร — ใช้ได้จริงกับตัวแปรไม่มาก
Radar/Spider Chartแต่ละแกนพุ่งจากจุดศูนย์กลาง 1 แกน = 1 มิติ เชื่อมจุดเป็นรูปหลายเหลี่ยมพื้นที่รูปหลายเหลี่ยมบิดเบือนได้ง่าย ขึ้นกับลำดับแกนที่วาง (Surfacing Visualization Mirages, CHI 2020)
Parallel Coordinates Plotแต่ละมิติ = 1 แกนตั้งขนานกัน แต่ละแถวข้อมูล = เส้น polyline ที่ลากผ่านทุกแกนลำดับแกน (axis order) มีผลมากต่อ pattern ที่มองเห็น — ต้องลองสลับลำดับ

ทำไม 4D+ ถึงยาก: Many-to-One Mapping

Visual Mark 1 ชิ้นรับ Visual Variable ได้จำกัด — ยิ่งยัดหลายมิติเข้า mark เดียว (เช่น position x, position y, size, color, shape พร้อมกัน) ยิ่งเกิด many-to-one mapping ที่ตีความสับสน (Tamara Munzner, 2014).

Visual Variable Separability (Munzner, 2014)

คู่ Visual Variableระดับการรบกวน
Position + HueFully separable
Size + HueSome interference
Width + HeightSome/significant interference
Red + GreenMajor interference (ซ้ำปัญหา color blindness)

Simpson's Paradox

แนวโน้ม (trend) ที่เห็นในข้อมูลภาพรวม อาจกลับทิศทางเมื่อแบ่งข้อมูลเป็นกลุ่มย่อย (subgroup) — เช่น ภาพรวมเป็นขาขึ้น แต่ทุกกลุ่มย่อยกลับเป็นขาลง เกิดจากตัวแปรแฝง (confounding variable) ที่ไม่ได้แสดงในชาร์ต.
